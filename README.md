# Soy Iker Vericat y este es mi portfolio

Repositorio del código fuente de mi sitio web personal y portfolio, accesible en [ikervericat.dev](https://ikervericat.dev).

El objetivo del sitio es centralizar mi trayectoria laboral, formación técnica y proyectos destacados en desarrollo web y administración de sistemas.

---

## 🛠️ Stack Tecnológico

- **Framework:** [Astro](https://astro.build/)
- **Estilos:** [Tailwind CSS](https://tailwindcss.com/)
- **Lenguaje:** TypeScript
- **Despliegue:** GitHub Pages

```text
